# 2D Potential Flow Solver (FDM + Eigen)

Численный решатель для моделирования плоского потенциального обтекания тел произвольной формы методом конечных разностей (Finite Difference Method, FDM). Программа решает уравнение Лапласа для функции тока ($\psi$), восстанавливает векторное поле скоростей и поддерживает как аналитическое задание геометрии, так и импорт произвольного профиля из растрового изображения.

---

## Ключевые особенности

* **Физико-математическая модель:** потенциальное (безотрывное, безвихревое) обтекание несжимаемой идеальной жидкости.
* **Численный метод:** пятиточечный разностный шаблон второго порядка аппроксимации для двумерного уравнения Лапласа на структурированной декартовой сетке.
* **Линейная алгебра:** формирование глобальной разреженной матрицы коэффициентов и решение СЛАУ с помощью факторизации `Eigen::SparseLU`.
* **Импорт геометрии:**
  * Аналитические тела: круглый цилиндр, прямоугольник.
  * Произвольные профили: растеризация и картирование геометрии по бинарной/цветовой маске из изображения (`stb_image`).
* **Постпроцессинг:** вычисление компонент скорости $u = \frac{\partial \psi}{\partial y}$, $v = -\frac{\partial \psi}{\partial x}$, модуля скорости $\vert{}\vec{V}\vert{}$ и экспорт линий тока для дальнейшей визуализации.

---

## Математическая формулировка

### 1. Уравнение движения
В рамках модели потенциального течения поле скоростей выражается через функцию тока $\psi(x, y)$:
$$u = \frac{\partial \psi}{\partial y}, \quad v = -\frac{\partial \psi}{\partial x}$$

Условие безвихревости течения ($\nabla \times \vec{V} = 0$) приводит к уравнению Лапласа для $\psi$:
$$\nabla^2 \psi = \frac{\partial^2 \psi}{\partial x^2} + \frac{\partial^2 \psi}{\partial y^2} = 0$$

### 2. Граничные условия
* **Входной канал ($x = 0$):** условие Дирихле для однородного профиля скорости набегающего потока $U_\infty$:
  $$\psi(0, y) = U_\infty \cdot y$$
* **Верхняя и нижняя стенки ($y = 0, y = L_y$):** условие непротекания:
  $$\psi(x, 0) = 0, \quad \psi(x, L_y) = U_\infty \cdot L_y$$
* **Выход ($x = L_x$):** «мягкое» граничное условие (односторонняя разностная производная второго порядка):
  $$\frac{\partial^2 \psi}{\partial x^2} = 0 \implies 3\psi_i - 4\psi_{i-1} + \psi_{i-2} = 0$$
* **Поверхность тела:** условие непротекания твердой стенки (поверхность профиля является линией тока):
  $$\psi_{\text{body}} = \text{const} = \frac{U_\infty \cdot L_y}{2}$$

## Стек технологий и зависимости

* **Язык программирования:** C++ (стандарт C++17 / C++20)
* **Сторонние библиотеки:**
  * [Eigen 3](https://gitlab.com/libeigen/eigen) — шаблонная библиотека линейной алгебры (используются модули `Eigen::SparseMatrix` и `Eigen::SparseLU`).
  * [stb_image](https://github.com/nothings/stb) (Single-header library) — загрузка и парсинг растровых изображений (`.png`) для задания геометрии.
* **Система сборки:** CMake (>= 3.15)

---

##  Архитектура проекта

Код структурирован по модульному принципу:
* `Mesh` — генерация расчетной области, расчет пространственных шагов $\Delta x, \Delta y$, хранение координатных массивов узлов.
* `Telo` — интерфейс выбора и параметризации геометрии (аналитические примитивы).
* `Soedinenie` — маппинг геометрии на расчетную сетку (Immersed Boundary / Node Masking approach) и обработка растровой маски `telo.png`.
* `Reshatel` — сборка глобальной разреженной матрицы СЛАУ, наложение граничных условий, вызов солвера `SparseLU`, дифференцирование потенциала для получения полей скоростей и запись результатов.

---

## Сборка и запуск

### Предварительные требования
Убедитесь, что в системе установлен компилятор C++ (`gcc`, `clang` или `MSVC`) и доступна библиотека Eigen 3.

### Сборка через CMake

```bash
# Клонирование репозитория
git clone [https://github.com/](https://github.com/)VladislavIvanov1ivs/potential-flow-fdm-solver.git
cd potential-flow-fdm-solver

# Создание директории сборки
mkdir build && cd build

# Конфигурация и компиляция
cmake ..
cmake --build . --config Release
